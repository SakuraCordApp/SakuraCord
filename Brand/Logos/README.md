# SakuraCord logo exports

Each logo family contains PNGs at 1024, 512, 256, 128, 64, and 32 pixels.

## SakuraCord

- `with-background` uses the white SakuraCord mark and glass-rendered flower on
  a fully opaque, edge-to-edge SakuraCord gradient.
- `transparent` uses the Dark-appearance pink gradient on the SakuraCord mark
  while preserving the native Liquid Glass rendering.

## SakuraCord Flower

- `with-background` uses the glass-rendered flower on the fully opaque,
  edge-to-edge SakuraCord gradient.
- `transparent` preserves the native Liquid Glass flower rendering with
  transparent surroundings.
- `transparent/SakuraCord-Flower-Transparent-Liquid-Badge-72.png` is a 72×72
  profile-badge export, with the flower centered within a 60×60 artwork area.

## SakuraCord Contributor

- `transparent` preserves the native Liquid Glass twin-bud rendering with
  transparent surroundings. This family has no `with-background` variant.
- `transparent/SakuraCord-Contributor-Transparent-Liquid-Badge-72.png` is a
  72×72 profile-badge export, with the buds centered within a 60×60 artwork
  area to match the flower badge.

The editable source projects live in `App/Packaging`.
